# ServiceFlow 公开校园 FAQ 检索评测 v1

## 冻结方法（结果产生前确定）

从北京师范大学信息网络中心官网的 26 个公开页面整理 51 个答案证据单元。每单元有直接问法、口语描述、约束区分三种问法，共 153 题。它覆盖 VPN、无线网络、门户账号、邮箱、人脸门禁、校园卡和访客服务；不覆盖全部校园业务。

材料为依据原文整理的答案摘要，问题与相关性标注由 Agent 编写，`annotation_status=source_grounded_agent_authored`、`human_reviewed=false`。原文支持词已逐条与下载页面核验；核验来源词不能代替独立人工对全部语义与相关性判断的审核。它是**自建公开资料评测集**，不是官方发布的 IR benchmark，也不是用户真实问题集。多个答案均能完整回答时保留多个相关标签。未标注的结果不能被证明全部不相关。

主评测在固定 Top-5 下比较项目原有 BM25、Dense、Hybrid/RRF、Hybrid+Rerank 四种实现。四者使用完全相同的 51 个证据单元和 153 条查询；原问题、改写问题和标注均不进入索引正文。RRF 各分支候选数20，rank constant60，精排候选数10；保留当前配置，不按本集得分调参。

数据在模型调用前冻结，报告记录 dataset hash、corpus fingerprint、来源快照 hash、模型配置及检索代码 hash。模型调用成功结果在单独的忽略入库缓存中存储，配置或语料变化不会沿用旧缓存。Embedding 和 Reranker 均调用项目实际配置的远程模型；Reranker 不允许静默降级。云服务模型 revision 是配置标签，不能当作已经锁定供应商模型权重的证明。

报告计算 Recall@5、MRR@5、nDCG@5，以及三种问法的分层结果。置信区间采用逐来源网页的配对 cluster bootstrap（26组、10,000次、固定种子20261012）；同一原文的多条问题一起重采样，避免将153条改写问题视为完全独立的样本。预先报告 Hybrid/BM25、Hybrid+Rerank/BM25、Hybrid+Rerank/Hybrid、Hybrid+Rerank/Dense 四组差值。

## 运行方式

在 `agent-service/` 下运行：

```powershell
# 第一次下载源页面，核验支持词并生成来源清单；原始HTML只保存在本地缓存。
py -3.12 -m scripts.run_public_campus_retrieval_benchmark --collect-sources

# 使用 .env 中已经配置好的真实 Embedding / Reranker；已有完整报告禁止覆盖。
py -3.12 -m scripts.run_public_campus_retrieval_benchmark
```

来源清单已经入库，复现检索评测无需重新下载页面；数据摘要、问法、标签、来源链接均在 [benchmark.json](../agent-service/data/retrieval-evaluation/public-campus-v1/benchmark.json) 中。原始页面位于 `data/retrieval-evaluation/.cache/public-campus-sources/`，不会上传到 GitHub。模型向量和请求结果同样只缓存于 `.cache/`。生产知识库和在线索引不参与这次数据导入，不会因本实验改变。

来源页面包含不同年份的历史软件说明和政策，某些内容已过时。这些固定快照用于检索实验，不能直接当作今天的校园服务指南。Source URL 和 section 只证明检索证据有可定位出处；本轮不测 OCR、解析、模型最终回答准确率或生成答案的引用正确率。

简历可以选取该固定集上有证据支持的提升，注明自建公开校园 FAQ 集和比较基线。完整实验报告保留所有策略、分层结果和退化案例；不将单个 Smoke、小样本满分或自建集结果包装成生产效果。

## 2026-10-12 真实模型结果

测试集在 commit `2786c6e` 冻结后才调用模型。使用当前配置的 `qwen3.7-text-embedding-flash`（1024维）和 `qwen3-rerank`，四组实验均完成。完整逐题排名、分层分数及配置见 [JSON 报告](../agent-service/reports/public-campus-retrieval-v1-real-20261012.json)。

| 策略 | Recall@5 | MRR@5 | nDCG@5 |
| --- | ---: | ---: | ---: |
| BM25 | 0.908497 | 0.779521 | 0.812181 |
| Dense | 0.973856 | 0.874946 | 0.900389 |
| Hybrid/RRF | 0.973856 | 0.841939 | 0.875620 |
| Hybrid+Rerank | 1.000000 | 0.922331 | 0.942110 |

Hybrid+Rerank 较 BM25 的 MRR@5 绝对增加 `0.142810`、相对增加 **18.32%**；nDCG@5 绝对增加 `0.129929`、相对增加约 **16.00%**；Recall@5 增加 **9.15 个百分点**。这里的相对增加是 `(新值-基线)/基线`，不能把百分点和相对百分比混用。

按网页分组的配对95%置信区间：MRR@5 相对 BM25 的绝对差值为 `[+0.087597, +0.194545]`；相对 Hybrid 的差值为 `[+0.047561, +0.109229]`；相对 Dense 的差值为 `[+0.013593, +0.090580]`。这些区间支持固定集上的排序改善，但不会消除自建问题与标注的偏差。

| 问法（每类51题） | BM25 MRR@5 | Dense MRR@5 | Hybrid MRR@5 | Hybrid+Rerank MRR@5 |
| --- | ---: | ---: | ---: | ---: |
| 直接问法 | 0.905229 | 0.936275 | 0.931373 | 1.000000 |
| 口语描述 | 0.569935 | 0.804575 | 0.728431 | 0.825817 |
| 约束区分 | 0.863399 | 0.883987 | 0.866013 | 0.941176 |

153题中，精排较 BM25 的首个相关证据排名改善42题、退化7题、持平104题；精排有132题将相关证据放在首位。Recall@5=1.0 不代表所有答案都正确，也不代表153题均排第一。单独 Hybrid 的 MRR 低于 Dense，不能声称每一层都带来提升。

### 具体退化案例

| case_id | 现象 | BM25相关证据排名 | 精排相关证据排名 |
| --- | --- | ---: | ---: |
| `card-manual-freeze:colloquial` | 问休学后卡停用、充值是否有效，精排更偏向银行卡/充值段落，未将人工冻结条件排首位 | 1 | 4 |
| `card-bank:colloquial` | 问信用卡能否绑定自动转账，精排先放自动充值，绑定银行卡的资格约束排第二 | 1 | 2 |
| `vpn-campus:constraint` | 已在校内却提示无VPN权限，精排先放登录口令排障，校内连接限制排第二 | 1 | 2 |

这些结果保留在固定报告中；不删除难题，也不在得分之后调整标签或检索配置。退化反映模型会关注强主题词而忽略状态/资格约束，面试时可以具体解释后续诊断方向。

### 简历可用的一句话

> 基于26个高校官网页面构建153题公开校园FAQ离线评测集，采用BM25/Dense召回、RRF融合和Qwen精排，将MRR@5由0.780提升至0.922（较BM25相对提升18.3%），nDCG@5由0.812提升至0.942。

可选择这条正向成果，无需在简历正文逐项列举退化；标注口径、基线和原始报告仍需保留，便于面试复现。本次只提供候选文案，不修改用户此前要求保留的 Agent 简历文件。

参考的公开写法包括 [RAG项目的28题离线对照与简历示例](https://github.com/chitongx/rag-knowledge-base)和 [个人公开Agent简历](https://kieranjin.com/cv.html)。前者给出测试题数、对照策略和相对提升，并开放评测代码；后者以Recall/MRR前后值呈现结果，但无法据其页面独立验证原始数据。这些是写法参考，不是招聘效果或指标门槛的证据。参考项目的指标实现还存在不同口径，不能直接横向比较其 nDCG 分数。我们的 nDCG 使用项目已有的 `log2(rank+1)` 折扣公式。
